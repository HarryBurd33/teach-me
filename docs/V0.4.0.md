# Teach-me v0.4.0

## Plan and delivered scope

1. Add exact-source quote/spans and digest checks for model-assisted graph proposals; apply/edit only to new validated graphs and preserve joint premises/provenance.
2. Add immutable journey revisions and an atomic HEAD pointer; restore explicit verified revisions into new destinations.
3. Add three-way archive comparison and digest-bound whole-file conflict choices; preserve every input and refuse unresolved output.
4. Stage JSON/HTML reports before atomic create-if-absent publication; preserve another writer's replacement result on failure.
5. Scope learner facts and assumptions to the current journey, including unknown equipment and zero versus missing time.
6. Run deterministic tests, independent frozen checks and real model/tool examples; install/publish only accepted hashes with rollback.

Python 3.9+ standard library, original MIT material, progress schema v1 and prior activation/safety contracts are retained. These tools do not add an API client, scheduler or background service. See [the skill README](../teach-me/README.md), [graph workbench](../teach-me/references/graph-workbench.md) and [journey versions](../teach-me/references/journey-versions.md).

## Validation

- **125/125 tests pass against both the integrated candidate and actual global installation:** old 70 regressions, atomic 8, graph 15, versions 17 and independently frozen 15 checks. Public copies change frozen-test path defaults only; assertions are retained.
- **Independent review accepts candidate2.** All 15 frozen tests pass, including competing snapshot processes, failed HEAD activation, inactive-orphan preservation, archive conflicts and actual SIGKILL before publication. Candidate2 changed only two documentation files; all 30 hashes match the final manifest.
- **4/4 actual model responses meet their scoped checks, zero critical failures.** A separate executor created/checked/applied/edited a source-grounded graph, generated its existing viewer, snapshotted/restored four matching files, and made a verified conflict-free merged archive. Its unknown-equipment and zero/unknown-time responses remained scoped to new learners.
- **Direct narrow baseline benefits were observed.** The same injected half-write left an invalid partial final report in v0.3.0 and no final report in v0.4.0. A separately injected foreign-destination/fsync failure deleted the replacement result under v0.3.0, while v0.4.0 preserved it. These are synthetic fault cases, not real power-loss or hostile-system guarantees.
- **Global install/native discovery:** all 30 installed/source hashes match; Codex returns enabled user scope from two working directories without a model turn. Previous v0.3.0 is retained for rollback. ZIP CRC/member hashes are verified separately.

The current baseline intake examples also passed, so this is not evidence of causal or universal tutoring improvement. Model contexts were shared/nonblind; the executor previously constructed the graph component, and exact model/effort/cost were unknown. Simulated learners are not real retention/transfer outcomes. The unchanged viewer renderer is covered by existing regression tests and new generated-HTML checks; no new real-browser claim is made for this release.

## What still needs work

| Boundary | v0.4.0 improvement | Remaining work or limit |
| --- | --- | --- |
| Graph creation/editing | Source-grounded proposal structure, exact spans/hashes, explicit edits and existing safe viewer | Semantic inference and truth need review; no unattended extraction, semantic search, force-directed editing or upstream writeback |
| Journey continuity | Immutable stored revisions, atomic active snapshot and explicit restore | Does not make arbitrary live edits transactional; local cooperative locks, no distributed/background sync or automatic pruning/recovery |
| Conflict resolution | Three-way whole-file decisions with report-bound explicit conflicts | A byte-clean merge can still contain cross-file semantic contradictions; inspect combined plan/progress/source meaning before resuming |
| Snapshot contents | Required records and four named optional Markdown companions | Graph/proposal JSON, media, source code and arbitrary attachments are outside the seven-file archive allowlist and need separate reviewed handling |
| Output durability | Complete staged report appears atomically, foreign destination preserved | Hard kill may leave orphan staging files; unsupported hard-link filesystems fail closed; no universal power-loss or hostile-filesystem guarantee |
| Learner intake | Explicit current-learner fact/unknown/assumption discipline | Model behavior remains variable; this release does not prove perfect intake or eliminate every unsupported assumption |
| Other platform/host features | Existing bounded runner and capability-aware integrations | No OS sandbox, detached/Windows descendant guarantee, paid provider/speech/scheduler service or automatic native host selection proof |
| Learning effectiveness | Existing pilot templates and evidence rules | Actual consenting learners, delayed retention/transfer and qualified physical supervision remain necessary; simulated prompts are not outcomes |
| Native data support | Existing tested native-v1 subset plus original graph tools | More real/legacy fixtures, native roundtrip/writeback and broader integration need separate scope and rights checks |

No additional setup is required for included text/local tools beyond available Python/browser support. Archives and snapshots transport selected data, not credentials, permissions, jobs or learning competence. Prior version rollback will be preserved at installation.
