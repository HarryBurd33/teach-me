# Teach-me v0.11.0

A read-only preflight now checks exact reviewed merge choices before creating any draft. It reuses existing plan, graph and metadata validation, verifies both review hashes, recomputes the plan and rereads all five sources before success. The report gives the prospective ordinary v1 draft SHA256/bytes, record counts and sorted changed IDs. The new helper creates no files and disables import bytecode cache writes. Invalid inputs return status 2 with a diagnostic; no success report is printed.

The helper does not grant approval, reserve a destination or guarantee a later write. Apply independently revalidates and creates a new file. Existing 14 helpers and three editor assets remain byte-identical to v0.10.0, preserving the old data schemas and AND-premise/metadata behavior. No new runtime dependency, service, account or paid API is introduced.

## Validation

All **512 checks passed** against both candidate and global installation: 475 prior checks, 22 constructor methods and 15 independent methods frozen before candidate inspection. All **51 skill files** match the accepted candidate and installation; native enabled user-scope discovery passed from two directories. Existing helper/editor/old-test bytes were preserved. The frozen independent inventory mistakenly stated 16 methods; actual discovery ran 15, with no removed or weakened cases. Constructor fixture corrections and baseline feature-absence failures remain recorded. v0.10.0 is retained locally for rollback.

## Remaining limits and next work

Preflight detects invalid combinations; it does not repair them or deduplicate logical arguments. Same complete exact base, whole-record choices, 2 MiB draft/decision bounds, 8 MiB plans and 256 claims/arguments remain. No autosave, native writeback, distributed sync, semantic merge, identity authentication or encryption is added. A source can change after checking; approval and apply revalidation remain required.

Real learner baseline/retention/transfer trials, screen-reader user studies, installed Safari/Edge qualification, full Windows filesystem qualification, incomplete-archive reconstruction and hostile-writer/power-loss guarantees require separate work. Playwright WebKit is not installed Safari. See the [phased roadmap](ROADMAP.md) for acceptance gates. No learner-efficacy or model-superiority claim is made.

The baseline is the project's own MIT v0.10.0 source. Astra/Extra High planned and reviewed; a Sol/Medium constructor implemented the helper and separate Astra/Extra High evaluator froze tests before candidate inspection. These are observed assignments, not a cost or superiority comparison. The one-use planning schedule was deleted before work resumed.

Initial remote Python CI ran all 512 methods but 16 failed because two newly ported tests retained a private candidate-directory default. Only those default paths were adapted; all test function/class ASTs and original frozen evidence remained unchanged. Product files were unchanged. The first 40-case browser matrix passed.
