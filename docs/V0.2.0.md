# Teach-me v0.2.0

## Capabilities

- Diagnostic, teaching, practice and review modes; prerequisite repair through prediction, explanation and a fresh check.
- Mixed practice without method labels when selecting a method is part of the target; graduated help and assistance-aware evidence.
- Optional knowledge and practice records: sourced propositions, prerequisite links, jointly required premises, attempt summaries, feedback and next retrieval tasks. Maps and confidence are separate from demonstrated learning.
- A small harness-engineering learning track: instructions, tools/environment, state, verification/feedback and scope/lifecycle. One active feature, an exact pending check, a controlled comparison and a next-session handoff.
- Selective read-only inspection of relevant supplied LearnHarness exports through host file tools, with explicit unknown-format and privacy boundaries.

Progress schema v1 and the Python 3.9+ standard-library helper are unchanged. Old journeys require no migration. The helper still initializes only plan.md, progress.json and sources.md; the tutor creates optional Markdown records with authorized file tools.

## Remaining limits and next steps

| Limit | Next useful step |
| --- | --- |
| No native importer or complete upstream format compatibility | Separately scope a versioned read-only adapter, inspect applicable rights, build representative native/legacy fixtures, and test answer matching, shuffled options, malformed records and provenance. |
| No automatic graph extraction, viewer or synchronization | Define the required graph schema, conflict/ownership/privacy rules and round-trip tests before adding an optional integration. The current knowledge map is Markdown. |
| No scheduler, dictation engine, autonomous loop/graph runner or provider integration | Choose a supported host/runtime, permissions and enforced budgets; test success, failure, interruption and rollback. The current engineering track teaches design and local experiments. |
| Simulated learner tests do not prove learning effectiveness | Run consented real-learner pilots with delayed retention and transfer tasks. Keep claims scoped to observed evidence. |
| Media and physical performance depend on host tools and qualified supervision | Verify the actual supported media channel; hazardous physical practice still requires suitable supervision and cannot be certified remotely. |
| Single-writer local records, no multi-file transaction | Use one writer and preserve backups. A future synchronization feature needs explicit concurrency/conflict/recovery testing. |

No additional setup is needed for the included text/local-record workflows. Web research and file persistence require corresponding host tools and authorization. A written project budget is not runtime enforcement.
